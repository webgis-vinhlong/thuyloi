# WebGIS Hệ thống Thủy lợi Bến Tre

Repository đang được khởi tạo để phục dựng WebGIS quản lý và khai thác công trình thủy lợi tỉnh Bến Tre từ mã nguồn phục dựng, giao diện WebGIS hiện có và báo cáo nghiên cứu năm 2020.

> Commit khởi tạo. Mã WebGIS hoàn chỉnh được đưa lên nhánh triển khai ngay sau commit này.
